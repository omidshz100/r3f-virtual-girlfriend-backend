📋 Project Overview

This project presents an Innovation-driven AI System designed to enhance Human-Computer Interaction (HCI) through a realistic, real-time Virtual Companion. The system addresses the societal need for digital emotional support and immersive conversational interfaces by integrating advanced 3D rendering with Generative AI.

The system follows a System-Centric architecture composed of three main subsystems: Sensors (Perception), Cognition (LLM Reasoning Engine), and Actuators (3D Avatar Rendering with real-time lip-sync).

✨ Key Achievements

🧠 LLM-Powered Reasoning

Natural, emotionally-aware conversation using state-of-the-art language models with structured JSON output.

🎙️ Speech Synthesis

Realistic vocal delivery with diverse voice IDs and tone control using ElevenLabs TTS API.

🎭 Real-time 3D Animation

Expressive avatars with synchronized lip movements and facial expressions using React Three Fiber.

☁️ Scalable Deployment

Web-accessible interface deployable on serverless platforms with graceful fallback behavior.

🛠️ Technology Stack

Node.js + Express OpenAI GPT-3.5 ElevenLabs TTS React Three Fiber FFmpeg + Rhubarb Vercel Serverless RESTful API WebGL

🏗️ System Architecture

Functional Pipeline (Perception → Cognition → Action):

  • Sensors/Perception: User text or voice input capture
  • Data Conditioning: Request parsing and prompt formatting
  • ML/Cognition: LLM generates context-aware, emotionally-aware responses
  • Computing/Orchestration: TTS conversion and animation metadata generation
  • Human-Machine Teaming: 3D avatar renders synchronized speech with expressions

⚡ Primary Engineering Challenge

Latency Optimization: Minimizing latency in the audio-to-animation pipeline to prevent "uncanny valley" effects where visual feedback (lip movement) lags perceptibly behind audio output.

Solutions Implemented:

  • Fallback to writable temp directory (/tmp) for serverless environments
  • Graceful degradation when ffmpeg/rhubarb unavailable
  • Prompt optimization for faster LLM generation
  • Parallel processing for batch TTS requests
